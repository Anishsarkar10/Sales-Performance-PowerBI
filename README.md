# Sales Performance Analysis Dashboard | Power BI

## Project Overview
This project focuses on analysing sales performance using Power BI. The dashboard provides insights into sales trends, regional performance, product performance, customer segments, and store performance to support data-driven business decisions.

## Project Objectives
- Analyse overall sales and profit performance.
- Identify top-performing regions and product categories.
- Track monthly sales trends.
- Identify top-performing products and stores.
- Understand sales distribution across customer segments.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Orders
- Profit Percentage

## Key Business Insights
- **Top Region:** East – Rs. 434830K in sales.
- **Top Category:** Technology – Rs. 539402K in sales.
- **Peak Sales Month:** August 2022 – Rs. 33,382,993.
- **Top Product:** Product_375 – Rs. 3,387,110 in sales.
- **Top Store:** Store_82 – Rs. 8,069,912 in sales.

## Dashboard Features
- Interactive date range slicer.
- Region and category filters.
- Monthly sales trend analysis.
- Sales by region and category.
- Top 10 products by sales.
- Customer segment analysis.
- Store performance analysis.
